# PLID Connect
 
A terminal-based health records management system for patients with Prolapsed Lumbar Intervertebral Disc (PLID) and spine-related conditions.
 
## What It Does
 
PLID Connect lets patients create an account, log in, and manage their personal health records. Based on the data entered, the system automatically generates personalized health guidance and recommends verified spine specialists.
 
## Features
 
- **User Registration & Login** — Secure account system with duplicate username prevention
- **Add Patient Record** — Stores age, gender, disc level, severity, height, weight, and auto-calculated BMI
- **Search Record** — Look up your saved health data by username
- **Update Record** — Edit any field in an existing record
- **Delete Record** — Permanently remove a patient record
- **Health Guidance** — Automated tips based on severity level and BMI
- **Doctor Recommendations** — List of verified PLID and spine specialists
- **About PLID** — Information on causes, risk factors, and the application
